💳 FLUJOS DE PAGO
================================================================================

1️⃣  Depósito con Tarjeta
    Usuario → Ingresa monto
    Frontend → Crea Payment Intent
    Stripe → Procesa pago
    Backend → Confirma y actualiza balance
    WebSocket → Notifica en tiempo real

2️⃣  Webhook de Confirmación
    Stripe emite: payment_intent.succeeded
    Backend → Verifica firma
    Backend → Actualiza transacción
    Backend → Emite evento WebSocket
    Usuario → Ve balance actualizado

3️⃣  Retiro de Dinero
    Usuario → Solicita retiro (requiere KYC)
    Backend → Deduce balance
    Backend → Crea transacción pendiente
    Admin → Procesa manualmente
    Usuario → Recibe en 1-3 días hábiles

📡 ENDPOINTS PRINCIPALES
================================================================================

Crear Depósito:
   POST /api/payments/create_deposit_intent/
   Body: {"amount": 50.00}
   Response: {client_secret, payment_intent_id, publishable_key}

Confirmar Depósito:
   POST /api/payments/confirm_deposit/
   Body: {"payment_intent_id": "pi_XXXXX"}
   Response: {status: "completed", new_balance}

Crear Retiro:
   POST /api/payments/withdraw/
   Body: {"amount": 100.00, "withdraw_method": "bank_transfer"}
   Response: {transaction_id, status: "pending"}

Agregar Tarjeta:
   POST /api/payments/add_payment_method/
   Body: {"payment_method_id": "pm_XXXXX"}
   Response: {success: true, last_four: "4242"}

Listar Tarjetas:
   GET /api/payments/payment_methods/
   Response: [{id, type, last_four, nickname}, ...]

Obtener Balance:
   GET /api/payments/balance/
   Response: {balance, bonus_balance, total}

💻 EJEMPLO FRONTEND (Stripe Elements)
================================================================================

```html
<form id="payment-form">
    <input type="number" id="amount" placeholder="Monto">
    <div id="card-element"></div>
    <button type="submit">Depositar</button>
</form>

<script src="https://js.stripe.com/v3/"></script>
<script>
const stripe = Stripe('PK_TEST_KEY');
const elements = stripe.elements();
const card = elements.create('card');
card.mount('#card-element');

document.getElementById('payment-form').addEventListener('submit', async (e) => {
    e.preventDefault();

    // 1. Crear Payment Intent
    const res1 = await fetch('/api/payments/create_deposit_intent/', {
        method: 'POST',
        headers: {'Content-Type': 'application/json'},
        body: JSON.stringify({amount: 50.00})
    });
    const {client_secret} = await res1.json();

    // 2. Confirmar pago
    const {error, paymentIntent} = await stripe.confirmCardPayment(client_secret, {
        payment_method: {card}
    });

    if (error) {
        alert('Error: ' + error.message);
        return;
    }

    // 3. Confirmar en backend
    const res2 = await fetch('/api/payments/confirm_deposit/', {
        method: 'POST',
        headers: {'Content-Type': 'application/json'},
        body: JSON.stringify({payment_intent_id: paymentIntent.id})
    });

    const data = await res2.json();
    alert('Depósito de $' + data.amount + ' exitoso!');
});
</script>
```
