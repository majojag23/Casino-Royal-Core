PASO 1: ENTRAR A LA CARPETA
════════════════════════════

cd Desktop/casino-online

════════════════════════════

PASO 2: CREAR ENTORNO VIRTUAL
══════════════════════════════

python -m venv venv
venv\Scripts\Activate.ps1

(Deberías ver (venv) al inicio de la terminal)

════════════════════════════

PASO 3: INSTALAR DEPENDENCIAS
══════════════════════════════

(Espera 5-10 minutos)

════════════════════════════

PASO 4: EJECUTAR MIGRACIONES
═════════════════════════════

python manage.py migrate

(Deberías ver "OK" varias veces)

════════════════════════

ENDPOINTS API DISPONIBLES
═══════════════════════════

1. AUTENTICACIÓN
   POST /api/users/auth/register/    → Registrar usuario
   POST /api/users/auth/login/       → Login
   POST /api/users/auth/forgot_password/  → Recuperar contraseña
   POST /api/users/auth/reset_password/   → Reestablecer contraseña

2. USUARIOS
   GET  /api/users/profile/          → Mi perfil
   PUT  /api/users/update_profile/   → Actualizar perfil
   POST /api/users/change_password/  → Cambiar contraseña
   GET  /api/users/login_history/    → Historial de logins

3. JUEGOS
   POST /api/games/play_slots/       → Jugar Slots
   POST /api/games/play_panda_mines/ → Jugar Panda Mines
   GET  /api/games/history/          → Historial de juegos

4. PAGOS
   POST /api/payments/deposit/       → Crear depósito
   POST /api/payments/withdraw/      → Crear retiro
   GET  /api/payments/transactions/  → Ver transacciones

5. ADMIN
   GET  /api/admin/dashboard/        → Dashboard admin
   GET  /api/admin/users/            → Listar usuarios
   POST /api/admin/suspend_user/     → Suspender usuario
   GET  /api/admin/transactions/     → Ver todas las transacciones
